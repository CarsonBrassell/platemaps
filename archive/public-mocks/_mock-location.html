My location — five treatments

Same block of the Gaslamp behind each one, so the marker is judged against the embers it has to live among.

A

Cool beacon

The familiar blue dot, made deliberately cold: the map has exactly one warm light source, so a cyan-white core can never be misread as a restaurant. The outer ring is the accuracy radius.

B

Cream ember

Speaks the map's own language — an ember like the restaurants, but cream-white and ringed rather than orange. The rings read as a slow pulse; caught here mid-breath.

C

Neon sign

Restaurants sign themselves above their bubble; you sign yourself the same way. Same mono neon voice, lit cold white instead of orange so it stays the one thing lit up that isn't a place to eat.

D

Reticle

An instrument mark rather than a place: hairline circle, four ticks, a small solid centre, dashed accuracy ring. Nothing glows, so it never competes with the city for attention.

E

Heading cone

The beacon plus which way you are facing — the cone fans out along the compass heading. Costs a device-orientation permission, and only earns it if walking directions ever land.
